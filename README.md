# عالم المستكشف الصغير / Little Explorer's World

قرية كرتونية لأطفال حوالي سنتين. تسعة بيوت تعليمية، عربي وإنجليزي، من غير إعلانات ولا مشتريات.

A cartoon village for toddlers (~2 years). Nine teaching houses, Arabic and English, no ads and no in-app purchases.

## ثبّته على أندرويد (تطبيق على الشاشة الرئيسية)

التطبيق جاهز يتثبت زي أي تطبيق أندرويد من كروم:

1. افتح الرابط في **Chrome** على الموبايل.
2. اضغط القائمة **⋮** أعلى اليمين.
3. اختار **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
4. هتظهر أيقونة البيت الأحمر مع اسم **المستكشف**.

من داخل اللعبة: اضغط مطوّل 3 ثواني على النقطة أعلى اليمين (بوابة الوالدين) ← حل الجمع البسيط ← **ثبّت على الأندرويد**.

يعمل أوفلاين بعد أول فتح (الصور والدروس تتخزن على الجهاز).

## للوالدين

- اضغط مطوّل 3 ثواني على النقطة أعلى اليمين ثم أجب مسألة جمع بسيطة.
- اختيار اللغة: عربي / الاتنين / English.
- كتم الصوت وإعادة تعيين النجوم.
- لا توجد حسابات ولا تتبع.

## Development

```bash
npm install
npm run dev
```

```bash
npm run typecheck
npm run build
```

Stack: TanStack Start, React 19, Tailwind CSS v4. Progress is stored in `localStorage` (`little-explorer-world`).
